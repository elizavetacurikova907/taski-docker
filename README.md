# 📋 Taski — Менеджер задач с контейнеризацией и CI/CD

**Taski** — это полноценное веб-приложение для управления задачами, состоящее из бэкенда на Django, фронтенда на JavaScript и веб-сервера Nginx в качестве шлюза. Проект полностью контейнеризирован с помощью Docker и настроен для автоматического развертывания через GitHub Actions.

Этот проект является частью учебного курса "Python-разработчик" Яндекс Практикума и демонстрирует навыки работы с полным циклом разработки: от написания кода до деплоя на продакшен-сервер.

---

## 🚀 Возможности проекта

- Создание, просмотр, редактирование и удаление задач.
- RESTful API для взаимодействия фронтенда и бэкенда.
- Полная контейнеризация приложения (бэкенд, фронтенд, база данных, веб-сервер).
- Автоматизированный CI/CD пайплайн: запуск тестов, проверка кода на PEP8 и автоматический деплой на сервер.
- Адаптивная верстка фронтенда.

---

## 🛠 Стек технологий

- **Бэкенд:** Python 3, Django, Django REST Framework, Gunicorn
- **Фронтенд:** JavaScript, HTML5, CSS3
- **База данных:** PostgreSQL (в production) / SQLite (для локальной разработки)
- **Контейнеризация:** Docker, Docker Compose
- **Веб-сервер:** Nginx
- **CI/CD:** GitHub Actions
- **Инструменты:** Flake8 (PEP8), pytest

🌐 Деплой на продакшен-сервер
Проект настроен для развертывания на удаленном сервере под управлением Ubuntu.
Убедитесь, что на сервере установлены Docker и Docker Compose.
Создайте файл .env в корневой директории проекта на сервере с необходимыми переменными окружения (секретный ключ Django, данные для подключения к PostgreSQL и т.д.).
Используйте продакшен-конфигурацию:
bash
docker-compose -f docker-compose.production.yml up -d
Nginx (в контейнере gateway) будет проксировать запросы к бэкенду и обслуживать статические файлы.
🔄 CI/CD (GitHub Actions)
В проекте настроен автоматизированный пайплайн, который срабатывает при push в ветку main:
Linting: Проверка кода Python на соответствие стандарту PEP8 с помощью Flake8.
Testing: Запуск юнит-тестов Django.
Build & Push: Сборка Docker-образов и отправка их в Docker Hub (или другой registry).
Deploy: Автоматическое подключение к серверу по SSH, обновление кода и перезапуск контейнеров.
Конфигурация пайплайна находится в директории .github/workflows/.
